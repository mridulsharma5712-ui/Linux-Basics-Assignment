# Linux Basics Assignment

## About
This repository contains my Linux Basics assignment
completed as part of the Tutedude DevOps course.

## Tasks Completed
1. Creating directories using mkdir
2. Creating files using touch
3. Renaming files using mv
4. Viewing files using cat
5. Displaying first lines using head
6. Displaying last lines using tail
7. Searching patterns using grep
8. Compressing directories using zip
9. Extracting files using unzip
10. Downloading files using wget
11. Changing permissions using chmod
12. Creating environment variables using export

## Project Structure
- Documentation.docx: Assignment documentation
